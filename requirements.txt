# Exact pin of the working virtual environment, for reproducibility on a new
# machine. See README.md for the full setup sequence.
#
# Direct dependencies:
#   fastapi, uvicorn, jinja2, python-multipart  -- the web service
#   opencv-python, mediapipe                    -- capture and face tracking
#   numpy, scipy                                -- signal processing
#   pytest                                      -- test suite
# Everything else is pulled in transitively and pinned so a fresh install
# cannot silently resolve to a different, incompatible version.
#
# TWO PINS ARE LOAD-BEARING. Do not let a resolver move them:
#
#   numpy<2       mediapipe requires it. numpy 2.x breaks mediapipe at import.
#   protobuf 4.x  mediapipe requires protobuf<5. Anything that drags in
#                 protobuf>=5 (streamlit>=1.61 is the usual culprit) breaks
#                 MediaPipe FaceMesh at *runtime*, not install time, with
#                 "FieldDescriptor object has no attribute 'label'".
#
# Install with:
#   pip install -r requirements.txt --only-binary=:all:
#
# The --only-binary flag matters: without it pip can fall back to building
# mediapipe or scipy from source, which hangs for a very long time.
